# WebSearch и WebFetch из архива

Перенесены механизмы и контракты из приложенного `claude-code-main(1).zip`:
`tools/WebSearchTool/{WebSearchTool,prompt}.ts` и
`tools/WebFetchTool/{WebFetchTool,utils,prompt,preapproved}.ts`.
TypeScript адаптирован к Python-агенту Layla. Подключение действует только
для ведущего Code и Code-воркеров с `files.read`. Общий legacy research service
и другие домены не меняются. Это не заявление о полном соответствии архиву.

## Поиск через Tavily

По последующему запросу пользователя `web_search` использует **Tavily Basic**,
независимо от LLM-провайдера. Это явная замена поискового backend из архива.
Контракт `query`, `allowed_domains` либо `blocked_domains`, обязательные ссылки
и поведение Confirm сохранены. Нативный архивный `native_search` остаётся
в коде как изолированный helper с проверками протокола, но агент его не выбирает.
Отсутствие ключа или ошибка Tavily возвращаются явно, без fallback.

Используется существующий зашифрованный ключ владельца из
**Настройки → Интеграции → Tavily**, таблица `intel_keys`, provider `tavily`.
Отдельного поля/секрета Code нет. Ключ заново читается перед каждым поиском;
обновление и удаление учитываются со следующего вызова. Чужие ключи,
ключ модели, проектные settings и содержимое чата не являются источником секрета.
UI использует общую карточку ключей интеграций. Список для этой страницы
запрашивается с `include_code=true` и отдельным query key; прежний список
источников и существующие lookup-инструменты не расширяются поиском Tavily.

Запрос: `POST https://api.tavily.com/search`, Bearer API key только в заголовке,
`search_depth=basic`, `auto_parameters=false`, `max_results=8`,
`include_usage=true`, без готового AI-ответа, изображений и полного raw content.
`allowed_domains` отображается в `include_domains` с restrict, `blocked_domains`
— в `exclude_domains`; фильтры повторно проверяются локально. До восьми
результатов содержат title, URL и выдержку до 4000 символов, без дублей.
Они обозначены недоверенными данными; агент должен приводить реальные ссылки.
Формат результата сохраняет `query/results/durationSeconds` и дополняется
`backend=tavily`, `sources`, `credits`, `request_id`, `search_depth`.

Сервис не вызывает LLM: общий ledger Code резервирует один поисковый кредит
и **ноль токенов модели** до HTTP. Используется отдельный тариф `tavily|basic`,
в панели бюджета — USD за 1000 запросов Basic (по умолчанию 8, можно задать 0
для бесплатного лимита или собственную цену плана). Это оценка, не счёт Tavily.
Поле `usage.credits` сверяет резерв; при отсутствии usage резерв сохраняется.
HTTP 4xx освобождает резерв; сетевой сбой/5xx/отмена сохраняют неизвестный расход.
Лимит USD может отклонить запрос до отправки даже без заданных цен токенов.

Автоматических повторов после неизвестного результата нет. Таймаут — 65 секунд,
HTTP-response ограничен 2 МБ, редиректы API не следуют, proxy env не используется.
Тексты upstream-ошибок и сетевых исключений не показываются пользователю:
они могут содержать секрет. Ошибки 401/403/429/432/433 показываются отдельно.
Архивный лимит восьми серверных поисков не применяется к Tavily: здесь один
вызов инструмента означает один Basic-запрос с восемью результатами.

Проверенный API-контракт и тарифы:
[Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search),
[Credits & Pricing](https://docs.tavily.com/documentation/api-credits).
Живые платные запросы в этом этапе не выполнялись.

## Чтение страниц

`web_fetch` требует **оба** аргумента: `url` и `prompt` извлечения информации.
HTTP повышается до HTTPS, credentials в URL и нестандартные порты запрещены.
Перед загрузкой выполняется архивная проверка публичного домена через
`https://api.anthropic.com/api/web/domain_info`; положительные решения
кешируются на 5 минут (128 доменов), ошибка сервиса не означает разрешение.
Таймаут проверки — 10 секунд. Архивная настройка
`skipWebFetchPreflight: true` в проектных `.claude/settings*.json` или
`.layla/settings*.json` отключает только эту проверку; DNS-защита остаётся.
Настройки фиксируются при подготовке запуска, локальные имеют приоритет.

Все DNS-адреса должны быть публичными, соединение закрепляется за проверенным
IP с исходными Host/SNI. GET не получает ключ провайдера, cookies или login
сессию. Общий таймаут загрузки — 70 секунд, ответ — до 10 МиБ. До десяти
перенаправлений внутри хоста (включая добавление/снятие `www`) следуют
автоматически. На другой хост запрос не отправляется: результат предлагает
новый вызов с новым URL, который снова проходит policy/Confirm/preflight.

HTML преобразуется в Markdown, script/style/template исключаются. До 100000
символов передаются отдельному вызову модели без инструментов с пользовательским
prompt. Выбирается включённая Haiku текущего провайдера, если она настроена,
иначе текущая модель; вызов использует общий бюджет Code. Исходная страница
обозначена как недоверенные данные. Для небольшого `text/markdown` с архивного
preapproved URL содержимое возвращается напрямую. Упакован список из 89
архивных разрешений, включая границы путей. В Confirm поиск и чтение
неразрешённого заранее URL требуют обычного подтверждения. Skill-ограничение
`WebFetch(domain:example.com)` проверяет точное имя хоста.

Кеш исходного GET живёт 15 минут, ограничен 50 МиБ и 512 записями, разделён
по владельцам. Новый prompt заново обрабатывает закешированную страницу.
DNS/preflight проверяются и перед чтением кеша. Результат сохраняет архивные
`bytes`, `code`, `codeText`, `result`, `durationMs`, `url`, добавляет источник
и сведения о кеше/модели. Двоичный ответ сохраняется как авторизованное
вложение Code с существующим лимитом 2 МиБ на файл и лимитами чата;
извлечение текста из PDF не реализовано. Для авторизованных ресурсов агенту
предлагается использовать настроенный MCP.

## Проверка и оставшиеся различия

`tests/test_code_archive_web.py` проверяет протокол поиска через настоящий
HTTP-парсер с тестовым transport, ротацию ключей, pause, ошибки, отмену,
бюджет/БД, Markdown, кеш/изоляцию, redirects, DNS, вложения и Confirm.
CI проверяет загрузку preapproved JSON из wheel.

Tavily возвращает ответ целиком; архивные потоковые progress events
подзапросов не перенесены. Vertex/Foundry transport, managed permissions и
полная архивная схема разрешений не реализованы. Markdown-конвертер Python
может отличаться от Turndown. Живые платные запросы и production-доступность
domain_info этим набором тестов не подтверждаются.

Зависимость WebFetch: `markdownify>=1,<2`. Для установки нужна пересборка
Core/frontend и `alembic upgrade head`. Миграция `0035_code_tavily` добавляет
метку Tavily в существующий PostgreSQL enum ключей интеграций (IF NOT EXISTS).
Она не создаёт нового хранилища и не заменяет существующие ключи. При downgrade
метка и ключи сохраняются: безопасное удаление enum-значения не поддерживается.
