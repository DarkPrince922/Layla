# Варианты направления для интерфейса Layla

Это предложения для отдельного этапа редизайна. Новые файловые функции используют
существующую тёмную тему; полный редизайн всех доменов в этот PR не входит.

| Референс | Что взять для Layla | Где особенно полезно |
|---|---|---|
| [Linear: разбор редизайна](https://linear.app/now/how-we-redesigned-the-linear-ui) | Нейтральные поверхности, чёткую типографику, аккуратные отступы и единые заголовки/панели | Общая оболочка, настройки, списки проектов и кейсов |
| [Cursor: работа с изменениями](https://cursor.com/learn/reviewing-testing) | Рабочее пространство вокруг дерева файлов, редактора, чата и просмотра дифов | Раздел «Код» и проверка результатов агента |
| [Replit](https://replit.com/) | Начало с описания задачи, понятные состояния создания проекта и постепенное раскрытие деталей | Новый проект и сценарии с телефона |

Рекомендуемое сочетание: визуальная основа Linear, организация кодового рабочего
пространства Cursor, простой старт из промпта по примеру Replit. Для телефона —
одна основная панель с вкладками, а не уменьшенная копия трёх колонок.

Следующий самостоятельный этап: согласовать направление, затем обновить общие
цвета, типографику, навигацию и состояния компонентов во всех четырёх доменах.
