# Оформление Layla — Aurora

Единая тёмная тема для Кода, Пентеста, OSINT, Дизайна, настроек и страницы входа:
графитовые поверхности, лавандовый акцент, мятное свечение, округлые панели,
тонкие световые границы и мягкие состояния кнопок. Активный раздел выделяется
собственным цветовым акцентом. Тексты и рабочие области остаются на спокойном
тёмном фоне.

Manrope Variable с кириллицей поставляется внутри приложения: для шрифта не
нужен доступ к Google Fonts или другим CDN. У кода остаётся отдельный
моноширинный шрифт. Заголовки используют более плотный набор, длинные ответы —
свободный межстрочный интервал.

Фон состоит из двух декоративных градиентов. Их медленное движение выполняется
CSS-трансформациями; нет видео, canvas, таймеров React или отслеживания мыши.
Декоративные слои скрыты от скринридера и не перехватывают клики.

В **Настройки → Внешний вид** доступен живой образец темы и переключатель
«Плавные переходы и переливы фона». Отключение сохраняется в браузере и делает
фон статичным, убирая движения экранов, сообщений и панелей. Системный
`prefers-reduced-motion` имеет приоритет даже при включённом переключателе.
Настройка применяется также на странице входа. Клавиатурный фокус виден;
эффекты наведения с перемещением включены только для устройств с мышью.

Изменения касаются оформления фронтенда. Новая миграция базы и изменения
серверного `.env` не требуются.
